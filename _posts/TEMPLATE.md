## 文章内容

在这里写你的文章内容。

### Front Matter 字段说明

- **title**: 文章标题（必需）
- **date**: 发布日期，格式 YYYY-MM-DD（必需）
- **tags**: 标签数组，用于细粒度检索（如：tauri, career, btc）
- **categories**: 分类数组，用于大主题分区（如：tech, work, thinking）
- **excerpt**: 文章摘要，用于列表页显示（可选，如果不填会自动截取前160字）

### 使用建议

1. **tags（标签）**：使用具体的技术、工具、概念名称
   - 示例：`[Python, Django, RESTful API, 数据库优化]`

2. **categories（分类）**：使用大主题分类
   - 示例：`[技术]`, `[职场]`, `[思考]`, `[工具]`

3. **excerpt（摘要）**：简洁概括文章核心价值
   - 好的摘要：`"深入解析 Python 装饰器的原理与应用，通过实际案例展示如何优雅地使用装饰器解决常见问题。"`
   - 避免：`"这是一篇关于 Python 的文章"`（太泛泛）
